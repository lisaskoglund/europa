## How to Use

### To Test
1. Open `index.html` in browser
2. Select a user
3. Navigate to Capitals or Study page
4. Complete quiz
5. Check results and highscores

### To Modify
1. Edit page-specific CSS in `css/page-name.css`
2. Edit page logic in `js/page-name.js`
3. Add shared functions to `js/shared.js`
4. Test in browser

### To Add New Page
1. Create `new-page.html`
2. Create `js/new-page.js`
3. Create `css/new-page.css`
4. Link `shared.js` first in HTML
5. Follow existing patterns
